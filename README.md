# Komorebi Browser

> A web browser with your animated wallpapers behind your tabs.

Komorebi is a browser based on Firefox. It shows your Wallpaper Engine
wallpapers, videos or images behind the home page, new tabs and Google results,
so your browser looks like your desktop.

## Download

Get `Komorebi-Browser-Setup.exe` from the
[latest release](https://github.com/foufouadi/Komorebi-Browser/releases/latest)
and run it. No administrator rights are needed. Windows only.

Windows may warn you the first time because the installer is not signed.

Komorebi updates itself from its settings. If you have version 0.1.0, install
the new version over it once by hand.

## What you can do

- Use your Wallpaper Engine wallpapers: Komorebi finds them on its own.
- Add your own images and videos by dropping them on the library.
- Some wallpapers react to the mouse.
- Read Google results on see-through blocks over the wallpaper.
- Bring in your bookmarks and history from Chrome or Firefox.
- Choose how much power the wallpaper uses. It pauses when you can't see it.

## Not supported yet

- Wallpapers that react to music.
- Changing a wallpaper's own options, such as its clock or colors.
- Web, application and 3D wallpapers.
- Some wallpapers still show small display glitches.
